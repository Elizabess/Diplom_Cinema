Сайт бронирования билетов

Технологии: 
- PHP 8.1+
- Composer
- MySQL / MariaDB
- Laravel

Структура проекта:
- `public/` - публичная директория
- `src/` - исходный код (Controllers, Models, Views, Services)
- `config/` - конфигурация (БД, приложения)
- `migrations/` - миграция БД
- `storages` - логи и временные файлы
- `vendor/` - зависимости Composer

Как запустить:
1. Склонировать репозиторий.
2. Установить зависимости: `composer install`.
3. Настроить `.env` ( копия с `.env.example`).
4. Настроить веб-сервер: документ-рут - `public/`.
5. Импортировать БД.

План разработки (кратко):

1. Архитектура и структура проекта.
2. База данных: сущности и миграции.
3. Авторизация и роли (админ / гость).
4. Админ-панель: залы, фильмы, сеансы, цены.
5. Публичная часть: расписание, выбор места, бронирование.
6. Генерация QR-кодов билетов.
7. Тестирование и оформление README.
