# Сайт бронирования билетов в кино

Веб-приложение для просмотра расписания киносеансов, выбора мест в зале, оформления бронирования и получения электронного билета.  
Предусмотрена административная часть для управления кинозалами, фильмами, сеансами и билетами.

## Технологии

- PHP 8.1+
- Composer
- MySQL 8 / MariaDB
- HTML, CSS, JavaScript
- PDO для работы с базой данных

cinema-booking/

## Функциональность

### Публичная часть

- Главная страница с фильмами и сеансами.
- Выбор кинозала и мест.
- Подтверждение бронирования.
- Электронный билет с QR-кодом.

Доступные маршруты:

```text
/                      Главная страница
/?page=hall            Выбор мест
/?page=payment         Подтверждение бронирования
/?page=ticket          Электронный билет
```

### Административная часть

- Вход администратора по email и паролю.
- Защищённая панель администратора.
- Выход из системы.
- В дальнейшем: управление залами, фильмами, сеансами, ценами и билетами.
